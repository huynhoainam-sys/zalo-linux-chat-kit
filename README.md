# Zalo Linux Chat Kit

Cài nhanh Zalo trên Ubuntu/Linux Mint, ưu tiên nhắn tin, lịch sử chat, hình ảnh và backup local.

## Cài

```bash
curl -fsSL https://raw.githubusercontent.com/huynhoainam-sys/zalo-linux-chat-kit/main/install-zalo-linux.sh -o install-zalo-linux.sh
chmod +x install-zalo-linux.sh
./install-zalo-linux.sh
```

Xem [HUONG-DAN-ZALO-LINUX.md](HUONG-DAN-ZALO-LINUX.md) để đồng bộ lịch sử và ảnh.
